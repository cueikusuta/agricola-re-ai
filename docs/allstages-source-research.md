# A〜Eカード 段階1〜4 文献裏取り（独立調査）

## 0. 目的・方法・独立性

- 対象リポジトリ: `cueikusuta/agricola-re-ai`。ルールの正本は2016年改訂版 Lookout 公式ルール。
- 本調査は PR #355 の分類（OR費用13枚・他人の手番42枚・畑になるカード5枚）を**検証対象**とし、
  同PRの成果物（`docs/layer1-2-card-survey.md` 等）を読まずに、文献と仕様データだけから独立に再分類した。
  比較に使ったのは PR #355 の本文に記載された件数と13枚のIDのみ。
- 第2章（段階3・4）は全カードを独立に走査して対象を割り当てた。
- 文献は次の2系統を使った。
  1. 日本語カードページ（第三者のBGA向けWiki）: `https://agricola.cloudfree.jp/?p=NNNN`。
     各ページの「基本情報」（No./区分/条件/コスト/勝利点）と「効果」を読んだ。
  2. 英語カード一覧（同じサイトの英語版）: `https://agricola.cloudfree.jp/cardlist_en/`。
     日本語版との食い違い検出に使った。独立運営の別Wikiではないため、**同一情報源の言語差**として扱う。
- 仕様データは `data/bga-card-specs/<ID>.json`（695枚）と `data/bga-card-base-ledger.csv`（840枚）を読んだ。
- カード原文・画像は転載せず、効果はすべて自分の言葉で要約した。各IDのURLは仕様JSONの
  `bga.references` から取れる。表の `p=` はその日本語ページ番号。
- 取得日: 2026-11-18。取得は1ページずつキャッシュし、robots.txt（`/wp-admin/` のみ禁止）に従った。

## 1. 第1章 段階1・段階2の裏取り

### 1.1 段階1: OR費用のカード

**抽出規則**: カードページの「コスト」欄が「A/B」形式で、支払う資源の束を選ぶもの。
「ラウンド7以降に出す」等のタイミング条件はOR費用に数えない。
「A, B/C」のようにカンマとスラッシュが混在する場合は、区切りの解釈を論点として残す。

日本語ページのコスト欄を全文走査すると、スラッシュを含むカードは13枚だった。
PR #355 の13枚とは A060 と D083 が入れ替わる。A060 は資源ではなく進歩の返却、
D083 は A004 と同じ「2飯/1小麦」型である。

**段階1の所見**

1. **集合のずれ（P1）**: 枚数は13で一致するが、A060 と D083 が入れ替わる。
   D083 は A004 と同型のOR費用で、規則を一貫させれば段階1に入る。
   A060 は資源ではなく「かまど/調理場の返却」で、CardZone 移動と複合カード種別を伴う別類型。
   13枚という数字だけを引き継ぐと、D083 の実装漏れと A060 の費用型誤認が同時に起きる。
2. **費用の記録方法がない（P1）**: 13枚すべてで `play.cost=null`、`alternative_cost_notes` に文字列で逃げている。
   B065 と C040 は「どちらで払ったか」が効果を決めるため、選択した費用を状態に保持しないと再現できない。
   スキーマに「費用の選択肢」と「選択結果」の表現が必要。
3. **費用文字列の破損（P2）**: E002/E030/E052/E053 の4枚で、Wikiの費用欄に `1_葦` のような
   アンダースコア混じりの文字列がある。E030 は選択の意味自体が読み取れない。
4. **区切りの解釈（P2）**: A064（1木,4レンガ/2石）と C044（2木/2レンガ,1葦）は、
   カンマとスラッシュの優先順位が文献から決まらない。実装前に人間の決定が要る。
5. **A060 の複合種別（P2）**: 小進歩と大進歩の両方に属する。どちらのデッキ枠・置き場所を使うかは
   文献だけでは決まらない。効果（変換表）自体は明確。

### 1.2 段階2: 他人の手番で発火するカード

**抽出規則**: 日本語ページの効果文に「他のプレイヤー」「他人」「相手」「ほかのプレイヤー」を含み、
かつ英語一覧にも another/other player 相当があるカード。42枚が該当した（PR #355 と同数）。

- **他者手番**: 他プレイヤーの行動をトリガーに、所有者が獲得・選択・支払いをする（28枚）。

- **自分側**: 自分の行動の結果、他全員が得をする（3枚）。
- **静的**: 得点・条件判定だけで、他者の手番イベントに反応しない（4枚）。

**段階2（他人の手番）の所見**

1. **42枚は発火条件の集合ではない（P1）**: 他者手番で発火するのは28枚、全員用スペースの通行料が3枚で、
   合計31枚。残り11枚は占有の上書き（4）、自分の行動で他者が得る（3）、静的（4）で、

2. **仕様のトリガー取り違え（P1）**: A150/A154/A158/A159 は注記の対象スペースが文献と違う。

6. **A050 の「誰か」トリガー（P2）**: 自分を含む任意プレイヤーの使用で発火する。

### 1.3 段階2: 畑になるカード

**段階2（畑）の所見**

1. **5枚は網羅でない（P1）**: 無条件のカード畑は9枚。C070/D075/E070/E072 が漏れている。
   D075 は「播種時は畑2、畑数としては1」という二重の数え方を持ち、実装難度は高い。
2. **仕様JSONの欠落（P1）**: D075/E070/E072 は仕様JSON自体が無い（全840枚中145枚が未作成）。
   文献には費用・条件・点・効果が揃っているため、まず仕様化できる。
3. **カード畑の農場スペース（P1・人間確認）**: 「カードが畑になる」場合、農場の1マスを使うのか、
   畑の数に数えるのか、柵・牧場の配置とどう関係するかが文献に書かれていない。
   B068/B113/B141/C070/E068/E069/E070/E072 の共通前提なので、実装前に決める必要がある。
4. **作物の種類（P2）**: D075/E068 は木材を作物として播種・収穫する。
   作物の enum を小麦/野菜だけに固定すると表現できない。
5. **最後の作物トリガー（P2）**: E068/E069/E070 は「最後の〜を収穫/取り除く」で追加効果。
   収穫処理の後にカード状態を見る必要があり、収穫の分割解決が前提になる。
