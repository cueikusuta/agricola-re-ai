# M6 カードA・B 2016年基本セットの効果分類（一次調査）

## 対象と重要な留保

2016年改訂版の基本収録分である A/B 各48枚、合計96枚（各24職業・24小改善）を対象にした一次棚卸し。拡張カードの追加分は対象外。カードの**原文・画像は一切収録せず**、以下は管理用ID、カード名と当プロジェクト独自の分類だけを記す。

出典の照合先：
- [Lookout公式Appendix](https://lookout-spiele.de/upload/en_agricolare.html_Appendix_Agricola-RE_EN.pdf)
- [Revised A基本セット一覧](https://agricola.veronahe.no/deck_RevisedA)
- [Revised B基本セット一覧](https://agricola.veronahe.no/deck_RevisedB)
- [カードID・基本セットの対応表](https://agricola.cloudfree.jp/cardlist_en/)

「即時」はプレイ直後、「常時」は行動・時点に応じた継続効果、「終了時得点」は得点専用、「複雑」は複数時点・任意選択・他人・予約・カード移動等の組み合わせを第一分類とする。**複数効果のカードは複雑側に仮置き**した。分類は初回の技術的トリアージであり、公式ルール照合・カード印刷値・人数別条件を検証して確定する。未実装を実装済みとみなして配布しない。

「後続実装の候補」としたものも、現時点で完成を意味しない。カード効果は同パターンのIssue単位にまとめ、1枚ごとのテスト、再演ハッシュ、カードの渡し先/得点を確かめたあと配布対象に加える。効果が曖昧ならIssueに根拠と影響を記録し推測実装しない。
