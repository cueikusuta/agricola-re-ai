## 第0章 目的・方法・出典

### 0.1 依頼と範囲

前回 #387 で照合した75枚を除く、現在の `origin/main` で実装済みのカードを対象とする。
対象の同定は第1章。結論として、追加対象は **C083 若牛** と **C147 牛の飼育士** の2枚である。
したがって第A章・第B章・第D章・第E章は「対象0枚」、第C章だけが実質の照合章になる。

### 0.2 方法

1枚ごとに次を突き合わせ、**仕様データの読み**が文献と合うかを見た。

1. 仕様データ `data/bga-card-specs/<ID>.json` の `play`（費用・前提・印刷点）と `effects`（トリガー・条件・手順・頻度・時点）、
   および `data/bga-card-tests/<ID>.json` の期待（仕様側の契約として扱う）
2. 文献の効果文（日本語の個別ページ、英語一覧）と、裁定（ルールブック付録、非公式コンピューディウム、BGAのルール説明）
3. 実装 `src/cards.rs` / `src/card_events.rs` / `src/engine.rs` / `src/registry.rs`（**読むだけ**。修正しない）

前回と同じく、条件の範囲（いつ・誰に・何回）、端数の処理、他プレイヤーが関わる部分を厚く見た。
今回は2枚とも「家畜の取得」であり、**置き場所がないときの端数処理**が中心論点になったため、
そこは公式ルール・付録・裁定集まで降りて確認した。
