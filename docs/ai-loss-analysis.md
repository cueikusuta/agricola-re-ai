# AI 敗因分析（Issue #106 / ロードマップ §4「AI改善のための分析」）

作成日：2026-11-06
対象：カードなしの自己対戦（2〜4人）。評価関数AI（`EvaluationPolicy`）と貪欲AI（`GreedyPolicy`）。

## 1. 目的と非目的

- **目的**：新しい探索アルゴリズムを先に追加せず、「評価関数AIはどこで負けるのか」を数えられる仮説へ分解する。各仮説は単独で効果を測れる小さな実験にできる形にする。
- **非目的**：強さの合否判定、探索AI（MCTS/PUCT）の実装・変更、カード込みの評価。既存の探索実装（PR #146）には触れない。
- 本ドキュメントの数値は**相関**であり原因ではない。改善候補は必ず同一seed・同一座席・同一相手構成の比較で採否を判定する（ロードマップ §3.1）。

## 2. 方法

診断ツール `src/bin/ai_diagnostics.rs` を追加した。カードなし自己対戦を固定seedで完走させ、各プレイヤーの終局観測量と失敗フラグを記録し、順位別に集計する。

- 意思決定ループは `policy::play_to_end_observed` と同一の構造・同一の手数上限（320）を用いる。`tests/ai_diagnostics.rs` が同一seedで最終 `state_hash` が正規ループと一致することを検証する。つまり診断結果は実際にプロジェクトが回す対局をそのまま記述している。
- ポリシーは `Observation` のみを入力にする。未公開のラウンド順序・内部乱数は使わない。
- 出力は決定的（ソート済み・タイムスタンプなし）。同一seed範囲で byte-for-byte 再現することをテストで固定する。
- 失敗フラグ：`begged`（物乞い）、`never_grew_beyond_two`、`late_third_worker`（3人目の家族がラウンド8以降）、`no_fields`、`no_pastures`、`empty_rooms`、`farm_left_unused`（空きマス5以上）、`no_animals`、`no_vegetables`。

再現コマンド（例）：

```bash
cargo run --release --bin ai_diagnostics -- \
  --players 4 --seeds 300 --seed-start 910000 \
  --policy eval --additional-action-space false \
  --output target/ai-diag/eval4p.jsonl \
  --summary-output target/ai-diag/eval4p-summary.json
```

| 指標 | eval | greedy |
|---|---|---|
| 物乞い合計 | 215 | 1282 |
| 1位の平均得点 | 18.9 | 18.2 |
| 最下位の平均得点 | 6.2 | −0.2 |

評価関数AIは貪欲AIより食料破綻（物乞い）を大幅に減らし、最下位の失点を抑える。一方で1位の得点上限はほぼ同じで、**上位を伸ばす方向の改善余地**が残る。また貪欲AIは家族増員が遅れやすく、その差が順位に効いている。

## 4. 仮説（優先順）

1. **野菜・畑の活用不足が最大の順位差**（両人数で最大の負の相関）。`VegetableSeeds` の取得、種まき、畑への投資が後回しになっている可能性。4人戦では1位でも野菜がほぼ0で、得点上限を下げている。
2. **農場の使い切り不足**。空きマスが5以上ある割合が1位でも高く、柵・畑・厩・部屋への資源配分が薄い。
3. **食料破綻（物乞い）は敗因の一部**。評価関数AIは貪欲AIより改善済みだが、なお非1位の16%で発生する。
4. **4人戦では家族増員の速さだけでは順位を説明できない**（3人目家族のラウンド差が小さい）。2人戦では説明力がある。
5. **席順の影響は小さい**（4人戦1位率 0.20〜0.31）。席順補正よりも戦略改善の余地が大きい。

## 5. 小さな実験候補（効果を測れる単位）

各実験は「同一seed・同一座席・同一相手」で `ai_diagnostics` の順位別指標と、必要なら `paired_eval` 相当の首位率で前後比較し、改善が確認できたものだけ採用候補にする。探索実装には手を入れない。

1. **野菜優先度の変更**：`VegetableSeeds` と種まき（`Farmland`/`Cultivation`）の評価重みを上げ、`no_vegetables` 率が下がるか測る。
2. **最終盤の農場充填**：終盤ラウンドで空きマス削減（畑・柵・厩）の重みを上げ、`farm_left_unused` と下位の得点を測る。
3. **収穫前の食料安全マージン**：収穫直前の食料しきい値を上げ、`begged` 率と最下位得点を測る。
4. **上位伸長の検証**：上記1・2の組み合わせで、1位の平均得点が上がるか（貪欲AIの18.2を超えられるか）を測る。

いずれも「首位率 +5 ポイント」の合否は本格評価（M12/M13、1,000試合・95%区間）で判定する。本分析はその前段の仮説整理である。

## 6. 制約

- カードなしのみ。カード込み4人戦はM10のプール整備後に対象へ追加する。
- ポリシーは eval/greedy/random のみ。MCTS/PUCT（PR #146）は本ツールに含めない。
- 4人戦カードなしは上位の得点が18点前後で、人間の目安（30〜40点）より低い。ルールの正しさではなく現行AIの弱さを示すもので、異常検知の補助として扱う。
- 予備計測であり、95%区間・ブロック・ブートストラップは未適用。
