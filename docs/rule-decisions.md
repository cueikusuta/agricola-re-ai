# ルール解釈記録

実装中に公式ルールと設計の不一致・曖昧さを発見したら、ここに典拠・候補・影響範囲・人間の決定を記録。

- 現状：未判断事項なし（公式ルールの照合は未完了）。

## 2026-11-04 公式付録に基づく確認済み修正

- **畑の得点**：0〜1枚は-1点、2/3/4/5枚以上は1/2/3/4点（Appendix p.11、"Field Tiles"）。初期ドラフトの誤った計算を修正。
- **パン窯**：Clay Ovenは1回のパン焼きにつき穀物ちょうど1→食料5、Stone Ovenは最大2→各4（Appendix p.2、"Major Improvements"）。上限を修正。
- **調理による野菜の食料化**：暖炉は野菜1→食料2、調理場は野菜1→食料3（Appendix p.2）。フリー変換を更新。
- **追加タイル**：4択の1つを選ぶとラウンド中ほか3つも使用不可。林の木材は選ばれなくても保持（Appendix p.8）。

### 追加で公式照合が必要

- パン焼きに複数の改善を同時利用する場合の細部指定を、現在の`bake: u32`から改善ごとの割当へ拡張すること。
- 柵の内部仕切り・牧場の拡張と分割の一般形を実装すること。
- 牛・羊・猪の物理トークン総数、一般供給の有限在庫と保有計算を完全に反映すること。

## 2026-11-04 M1追加検証：柵とパン焼き

- **牧場内の分割**：既存牧場を内部柵で分けることは認められる。2016年リバイズド版公式付録 p.7（Fencing）・ルールブック p.8（Animal Husbandry）。完成済みの外周柵を取り壊すことは認められない。`FenceDetailed` は分割後の牧場領域と家畜の配置を明示する。
- **パン焼き時の設備選択**：公式ルールブック p.10・付録 p.2。交換はいつでも自由な「パン焼き」アクションがある時だけ。各Clay Ovenは1粒を食料5、Stone Ovenは最大2粒を各食料4にする。複数設備の選択は新しい `BakeAllocation` で外部ポリシーから明示できるようにする。
- **追加したモデル**：`SowDetailed`・`BuyDetailed`。旧来の整数 `bake` はテスト互換のため残し、決定的な割当を実行する。
- **未解決**：入手した動物をどの牧場に割り当てるかと繁殖後の移動のルール細部、カードフックと収穫ポリシーのログ完全再現性は引き続き受け入れ前の検証対象。
