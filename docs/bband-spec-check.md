# B帯仕様データの文献照合（B帯147枚）

担当: Freebuff。ブランチ `research/freebuff-ab-bband-spec-check`（親: `research/freebuff-ab-spec-check`）。
PRは作成まで。**マージしない。**

## 第0章 目的・範囲・方法

A帯（`docs/aband-spec-check.md`）と同じ方法で、B帯（B001–B168）を1枚ずつ文献と突き合わせた。

### 0.1 既照合分の除外

| PR | B帯の対象 | 枚数 |
|---|---|---:|
| #387 `docs/impl-source-check.md` | 実装済みカード | 21 |
| #394 `docs/impl-source-check-2.md` | なし | 0 |
| #402 `docs/dband-spec-check.md` | B008をtravelingの校正用例に使用（対象一覧には無い） | 0 |

除外は B006, B007, B010, B013, B050, B057, B061, B062, B064, B077, B095, B098, B099, B102, B107,
B118, B121, B122, B126, B142, B144。B008 は #402 が校正に使っただけなので対象に含め、
`post_play`・効果とも一致を確認した。よって対象は **147枚**。

### 0.2 文献・等級・判定区分

A帯 0.3・0.4 と同じ。個別ページの `?p=` が別カードへ遷移するもの（B010, B013, B062, B095 ほか）は
英語一覧・日本語一覧・台帳で同定した。

### 0.3 B帯に多い構造的な問題

1. **語彙外の trigger / 述語 / kind**: `any_time`, `scoring`, `each_field_phase`, `on_use_*`、
   kind 無しの `other(description=...)`。表現不足70枚の大半がこれ。
2. **得点を資源として獲得**: `gain_resource(good="bonus_points")` が5枚（B029, B031, B034, B035, B038）。
3. **語彙外の品物名**: `brick`（B156, B163）、`boar`（B147, B165）、`card`、`action_space_use`、
   `family_growth`、`animal_of_owned_type`、`clay_or_stone`。
4. **`post_play: left_neighbor_hand`（17枚）**: 文献の効果文に「左隣へ渡す」文言が無い（第5章 Q-1）。

## 第1章 照合結果の集計

対象147枚。判定は **一致50・表現不足70・食い違い17・未確定10**。
費用・印刷点は147枚すべて台帳と一致（不一致0）。

**本PRはB帯の仕様データを変更しない。** 理由はA帯 0.6 と同じ制約による。

- 食い違い17枚は、いずれも `data/bga-card-tests/` のテスト契約が旧読みを前提にしている
  （得点の付与、二重取得、対象スペースなど）。テスト契約の再設計とセットでないと直せないため、
  第3章に文献の読みと修正案を残した。
- 表現不足70枚は、文献の読みを語彙で表せていないもの。語彙拡張（1.3節）が前提になる。
- 未確定10枚は第5章の質問に分離した。
