# 帯外（A/C/D/E 070〜120）の文献裏取りと独立分類

## 0. 目的・範囲・独立性

- 対象リポジトリ: `cueikusuta/agricola-re-ai`。ルールの正本は2016年改訂版 Lookout 公式ルール。
- 本調査は、段階1〜4の分類から外れていた **A/C/D/E の 070〜120** を、文献の裏付けと独立した分類で埋めるもの。
  コード・`data/bga-card-specs`・テストは変更しない。
- **独立性命題**: PR #370（`research/deepai-allstages-merged`）の本文と付録は読んだが、同PRの分類・裁定は
  追認も反駁もしていない。本調査の段階・基盤は、仕様データと文献だけを材料に、本節の基準から組み立てた。
  したがって #370 付録Aの区分や #361（`research/freebuff-allstages-sources`）の帯内の結論とは、
  一致しない箇所があってよい。比較は §6 に分離した。
- **枚数の相違（要確認）**: 依頼は「211枚」とするが、台帳（`data/bga-card-base-ledger.csv`）でも
  英語カード一覧でも、A/C/D/E 070〜120 は **各51枚・計204枚（欠番なし）** である。
  4帯×51番=204 が上限で、211には7枚足りない。本調査は実在する204枚を対象とし、
  211枚の内訳が別の名簿（版差・別デッキを含む等）に基づく場合は提示を求める（**Q-0**）。
  勝手に7枚を足していない。

## 1. 分類基準（本調査の定義）

依頼で確定済みの扱いを、そのまま基準に組み込む。

1. **OR費用は「資源の選択」ではなく「支払い候補の選択」**として数える。進歩や家畜を返して出す費用も同じ入口に入る。
2. **アクションスペースを増やす効果は共通機構に乗る**前提とし、そのカードの主軸判定では個性として数えない。
3. **帰宅フェイズに関わる効果を持つカードは段階3**に置く。

段階の判定順（上から評価し、最初に当てはまった段階を採る。枚数の二重計上はしない）。

| 順 | 段階 | 判定条件 |
|---:|---|---|
| 1 | **段階3** | 帰宅フェイズで発動する、または帰宅フェイズの解決内容を変える（決定済み扱い3） |
| 2 | **段階1** | 支払い候補の選択がカードの入口にある（OR費用、家畜を返す/調理して払う費用） |
| 3 | **段階2** | 発動サイトが自分以外（他者手番・いずれかのプレイヤー）、またはカード自体が畑・アクションスペースになる |
| 4 | **段階3** | 部屋・住居スロット・家族増加・改築という住居モデルを変える |
| 5 | **段階4** | 異なる発動時点が2つ以上あり、かつ操作系が3種類以上。またはカード上在庫（`STACK`）＋発動時点2つ以上 |
| 6 | **段階外** | 単一の発動点＋既存の原子操作の組み合わせで表せる。追加基盤は `必要基盤` 列に残す |

- 「アクションスペースを増やす」だけのカードは、順3のサイト判定で個性に数えない（決定済み扱い2）。
  追加スペース自体は共通機構の対象として `SPACE` を基盤列に記す。
- 家の材質を**条件**とするだけのカード（例: 石の家に住めば…）は、住居モデルを**変えない**ので段階3にしない。
  効果が部屋・住居・家族・改築自体に触れる場合だけ段階3とする。

### 1.1 必要基盤の記号

| 記号 | 意味 |
|---|---|
| `COST` | 支払い候補の選択と、選んだ候補の記録（OR費用・返却/調理による支払い） |
| `TR-WS` | 特定アクションスペースの使用をトリガーにする（自分の手番） |
| `TR-OTHER` | 他プレイヤーの手番をトリガーにする |
| `TR-ANY` | いずれかのプレイヤー（自分を含む）の使用をトリガーにする |
| `SPACE` | カードがアクションスペース（全員用・私的）になる |
| `FIELD` | カードが畑になる（播種・収穫の対象。多重数えを含む） |
| `ROUNDQ` | ラウンドスペースへの予約と、該当ラウンド開始時の受取 |
| `STACK` | カード上に品物・コマを置く在庫（保存・復元・再演ハッシュの対象） |
| `RH` | 帰宅フェイズ |
| `ROOM` | 部屋・住居スロット・部屋の収容人数 |
| `HOUSE` | 家の材質・改築経路 |
| `FAMILY` | 家族増加・新生児・人物の手番 |
| `PHASE` | 収穫・給餌・繁殖・労働フェイズなど、通常のラウンド境界以外の時点 |
| `SCORE` | 得点計算時の加点・条件判定 |
| `DISCOUNT` | 効果による費用の軽減・代替支払い |
| `ACT-GRANT` | 追加アクションの付与・アクションの置換 |
| `CAP` | 家畜の収容能力の変更 |
| `DEC` | 複数候補からの選択・順序決定 |
| `WORKER` | 人物の配置・回収・占有の操作 |
| `OCC` | 占有されていても使える等、占有規則の変更 |
| `BEG` | 物乞い |
| `ANYTIME` | 手番外の任意使用（「いつでも」） |

### A帯の所見

1. **点数差 A075（P2）**: 台帳は `printed_points=2`、Wiki の勝利点欄は「ー」。仕様JSONも2。版差か台帳の誤記かは
   文献だけでは決まらない（**Q-A1**）。既存のボーナス点台帳には触れていない。
2. **仕様の効果が空 A071/A092/A103（P1）**: 文献には明確な効果がある。仕様は `effects: []` のままで、
   実装すると無効果カードになる。
3. **条件の欠落 A073/A107（P2）**: A073 は「1アクションで未使用スペース2つ以上」、A107 は「そのラウンドの
   1/2/3番目の人物」と「資材がちょうど5/4/3」という条件が仕様に無く、トリガーだけが登録されている。
   実装すると毎回発火する。
4. **語彙外のトリガー A096/A110（P2）**: `stone_accumulation_space_revealed`、`after_clay_construction` は
   `docs/bga-card-effect-vocabulary.md` に無い。仕様の語彙追加か、既存トリガーへの読み替えが要る。
5. **新生児の状態 A092（P2）**: 増えた家族を同じラウンドに働かせると「新生児ではない」に変わる。
   給餌の要否が新生児フラグで決まるため、家族の状態に「新生児かどうか」を保存する必要がある。
6. **A102 の在庫（P2）**: カード上の8品は順序付きの在庫で、購入のたびに最上段が変わる。`STACK` の保存対象。
7. **A070 の「収穫のないラウンド」（P3）**: ラウンド終了時トリガーだが、収穫の有無で発火が変わる。
   `round_end` に収穫判定を組み合わせる形になり、ラウンド境界の共通処理に条件を1つ足す必要がある。
