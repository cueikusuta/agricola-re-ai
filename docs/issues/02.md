# M1 Issue 02: 合法手・適用処理：細部決定ポリシーとフリーアクション

依存: 1

## 実装範囲
合法アクション列挙→選択→細部パラメータ→検証→状態更新。柵／畑／種まき／家畜配置／改築をポリシーに依存。食料変換、家畜再配置、廃棄は非ワーカー操作として別経路。

## テストと受け入れ条件
不正入力拒否・状態非変更、パラメータの入れ替え、フリーアクションの時期。

## 運用
- 1 Issue = 1 ブランチ = 1 PR。PRに実装内容・テスト結果・未解決ルールを記載。
- 実装前に 2016年リバイズド版公式ルールと照合し、不明点は `docs/rule-decisions.md` に記載のうえ判断待ち。
- Side Jobは実装しない。UI・職業・小改善・MCTSは範囲外。
