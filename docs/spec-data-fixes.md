### 0.4 判定の原則

1. 日本語ページの効果文と、必要に応じてカード画像（費用・点数）を先に見る。
2. 英語一覧・非公式コンペンディウム・既存分類文書で日英差を確認する。
3. 1と2が一致するものだけ値を確定し、JSON を修正する。
4. 一致しないもの、公式裁定が必要なものは修正せず、第8章のチェックリストへ回す。
5. 他プレイヤーが関わる効果は、依頼どおり AI が実行してよいものとして構造化する。
   支払い不能時の扱いだけは既存の質問（H-1 / H-1b / MQ-16）に残す。
