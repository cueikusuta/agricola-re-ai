# M4: 3〜4人戦・ローカル人間対CPU

## 機能
- `Config.players` （2, 3, 4、デフォルト2）で人数可変。シード付きスタートプレイヤー、プレイヤー配列、ワーカー割当、イベントログ、保存復元・リプレイを人数に対応。
- 通常の3人戦ボード：林地（木2）、粘土の採取（粘土1）、資材市場（葦または石を1と食料1）。
- 通常の4人戦ボード：林（木1）、林地（木2）、粘土の採取（粘土2）、資材市場（葦1と石1と食料1）、旅芸人（食料1）。
- 追加タイルOFFが既定。ON時、2人戦は4択、3〜4人戦は家畜市場・家族増員の2択。同一ラウンドではいずれか1スペースを使用すると他のタイル上のスペースも使用不可。通常ボードの市場・林は影響を受けない。
- ローカルWebサーバは `127.0.0.1:8787` のみ。人間1P vs CPU最大3、画面から人数/追加タイル/AI/シード切替。農場・資源・得点・合法アクションを表示。
- 人間は行動スペースを選び、3人戦の資材市場は葦/石を選択。畑・柵・購入・動物配置などの詳細は現時点では`SimpleDetails`が自動生成。M4 UIの操作範囲はここまでであり、完全な手動プレイの細部指定は別途必要。

## 起動方法
```sh
cargo run --release --locked -- --web
cargo run --release --locked -- --players 4 --eval --seed 42
cargo test --release --locked --all-targets
```

## 版と制約
- 基準はLookout 2016 Revised付録の人数別アクションボード（特にpp.7–8）。公式原文・画像はリポジトリへ含めない。
- 手札なしバリアントのため職業をプレイするLessonsは除外。Side Jobなし。
- M3探索の井戸の将来配給予約は公開Observationから厳密再現できず、近似という制限を継承。
- リモート公開、マルチユーザー同時接続、対人オンラインプレイ、全細部の手動選択は対象外。
- UIに手作業の受け入れ・スクリーンショット検証は別途必要。
