# M5カード拡張／暫定M6・M7の範囲

`docs/design.md` が設計の正本です。同文書にはM5までしか定義されていません。ここで使う **M6/M7は正式仕様がないため暫定ラベル**であり、ユーザーによる正式な承認を意味しません。

## M5：実装済みのカード機能

- 既定は初心者向け手札なし。外部`CardSet`を明示した場合だけカードモード。
- プレイヤーごとに職業7枚・小さな進歩7枚を、ゲームシードにより決定的に配布。実装済みカードのプールだけを対象。
- カード定義はID・種類・支払い・得点・効果コードのみ。**公式カード本文・画像・全カードデータベースは公開リポジトリに同梱しません**。
- 職業: Lessons と ExtraLessons（人数別のコストあり）、小さな進歩: Meeting Place、Major Improvement、部屋が必要なFamily Growth。基本の手札なしモードは維持。
- 現在の効果語彙は `OnPlayGain` / `AfterWorkerGain` のみ。収穫・条件付き・特殊効果などの公式カード全体を網羅していません。
- 個々のカードの所在と得点を検証し、保存/復元/行動ログ再演に組み込みました。公開Observationは自分の手札と全員の枚数のみを返し、相手の手札IDと未配布カードIDは返しません。

## M6（暫定）：非公開情報への探索対応

MCTSは `Observation` だけを入力にします。自分の手札と全員の公開済み使用カードを固定し、相手の非公開手札と未配布カードをプレイアウトごとに再抽選します。未公開ラウンドカードもステージ内再抽選を続けます。

**制限**：探索木の枝はアクションスペース単位のままであり、完全な情報集合MCTSの保証はありません。カード使用の細部選択は `SimpleDetails` に依存します。井戸の将来配給予約が観測に含まれない近似は従来通りです。

## M7（暫定）：ローカル対戦UI

`cargo run -- --web` でローカルUIを起動し、設定欄で `CardSet` JSONを渡せます。手札なしなら入力欄は空欄のままです。「検証用の架空カードを生成」は公式カードを模したものではなく、システム動作を確認するためのオリジナルID/単純効果を必要枚数用意します。

カードモードでは1Pの手札のみを表示し、カードを選択してから対応するアクション（Lessons/ExtraLessons、Meeting Place、Major Improvement、Family Growth）を選ぶことでカードを使えます。相手の手札ID/未配布カードIDは画面にもAPIにも公開しません。

### 外部JSONの書式例

```json
{
  "definitions": [
    {
      "id": "sample_occ_0",
      "kind": "occupation",
      "cost": [],
      "points": 0,
      "effects": [
        {"AfterWorkerGain": {"space": "grain_seeds", "good": "food", "amount": 1}}
      ]
    }
  ]
}
```

サンプル単体は必要枚数を満たしません。2人戦では職業・小さな進歩を各14種類以上、4人戦では各28種類以上登録する必要があります。個別の公式カード効果を追加する場合は、カード1枚ごとにルール照合と回帰テストを行ってください。
