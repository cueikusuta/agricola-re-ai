## 目的とレイアウト
幅1280px（桌上／desktop）:
```text
┌────────────────────────────── Round 5/14 | 次収穫7 | 1Pの手番 ────────────────────────────┐
│  新規対戦 / 保存 / 設定...   [ドラフトは下位領域で引き続き操作可能]                       │
├─────────────────────────────────┬─────────────────────────────────────────────────────────┤
│  ACTION BOARD (左 約58%)       │  PERSONAL FARM (右 約42%)                              │
│  常設スペース                  │  1P 農場（5列×3行、部屋・畑・牧場・厩）                   │
│  [森林 木×n][葦×n][粘土×n]     │  ┌─┬─┬─┬─┬─┐   資源／家族／残ワーカー／点数               │
│  [漁 食×n][畑][部屋][柵]       │  ├─┼─┼─┼─┼─┤                                           │
│                               │  └─┴─┴─┴─┴─┘                                           │
│  ラウンド追加スペース          │  OPPONENT FARMS (全員、縮小5×3を順序固定で並べる)        │
│  [羊][進歩][家族増員]...       │  2P/3P/4P + 家族・資源・点数・残ワーカー                │
│                               │                                                         │
├─────────────────────────────────┴─────────────────────────────────────────────────────────┤
│  MY HAND      職業カード（展開可能） / 小さい進歩（展開可能）                            │
│  PLAYED CARDS 公開済みの進歩・職業（1P〜4P）                                            │
│  任意操作・履歴・ドラフト設定（展開・スクロールでアクセス）                                │
└───────────────────────────────────────────────────────────────────────────────────────────┘
```
幅390px: 状態/手番 → アクションボード → 自分の農場 → 他席の農場 → カード → 設定/ドラフトの縦フロー。
BGAの**情報の置き方**を参考にした独自のオリジナルCSS外観（木/農地/紙の質感）とする。

## 守るべき契約
- アクションボタンは必ず`#actions button[data-space]`、クリックで`openWork`（詳細モーダル）を呼ぶ。`available`と`public.used/accumulations/animal_accumulations`以外を根拠に合法性や未来のカードを推定しない。
- 自分の農場・他席の農場は`public.players`から描画。5×3のタイルにはサーバ由来の部屋/Field/Pasture/厩のみを描く。
- ラウンド追加スペースは`available`から表示。未開放カードは表示しない。占有済み一覧は`public.used`のみ。占有したプレイヤーの識別不能な場合は色を推測しない。
- `#farm/#stats/#hand/#cardBrowser/#tabs/#actions/#free/#new/#players/#draftPanel/#editor`等、既存Playwrightで使用中のID・公開APIは維持する。
- `renderCardBrowser`は`state.hand`を1P表示時に限り描画し、他席の非公開手札を表示しない。プレイ済みカードは公開状態のデータのみ。
- モーダルの農場ピッカー、柵候補、保存復帰、ドラフト、任意操作は既存ロジックを維持する。
- CI環境では日本語フォント（Noto CJK）を整備し、文字化け/豆腐表示のスクリーンショットを品質合格扱いしない。

## 合格ゲート
1. Chrome 1280×800でアクション盤と自分の農場の位置関係（横並び）、見切れ/横はみ出しなし。各スペースに資源または説明・占有表示。画像を人が確認可能なArtifactとして保存。
2. 390×844と768×1024で横はみ出しなし・農場5列が読める・Enter/Escape操作可能。
3. 2人/4人で他席の農場・資源が同時表示され、他席手札が見えない。ラウンド設定の差異に追随する。
4. 既存Playwright Browser UI E2E、Full Game 4条件×14ラウンド、Rust CI/ScriptテストがHEAD一致で緑色。UI操作ができても見た目に破綻がある場合は未完成扱い。
5. PRは#245へ積み、カードエンジン#236と他セッションのブランチを変更しない。
