# A〜Eカード台帳：一次分類と実装順序

## 目的
アグリコラ リバイズドの**人間が遊べる4人戦**と**強い対戦AI**を共通カード基盤で実現するため、A〜Eのカードを管理する。
本書と `card-catalog-ae-preliminary.csv` は一次調査資料であり、公式カードの正確な実装を保証するものではない。

## 内容
- A〜E各168枚、計840件の ID、種別、日英カード名、基本セット収録フラグ、効果分類タグ、実装難度を一次登録。
- 日本語名は参照資料の表記（正式訳・非公式訳が混在しうる）で、公式カード原文・全文効果・画像は**収録しない**。
- 効果カテゴリと難易度は説明文の語句から生成した**自動推定値**。各カードの正確な効果・費用・発動順序・前提・得点・人数制限は、ルール一次資料とカード現物を照合して改めて記録する。
- 複合カード種別（A060、D025、D059、D060）や他プレイヤーが関与するカードは、既存エンジンの型・イベント設計が必要なため必ず個別設計を行う。
- D025、D159は通常一覧に載らないため、別の未実装一覧からIDと日本語名を補った。
- カードIDは保存・再演・AIの内部キー。表示テキストや日本語名は別管理する。

## 暫定難易度（1〜5）
1. 即時または終了時に単純な処理。追加の選択や横断参照はない候補
2. 通常のアクション・ラウンド・収穫に対する単純な定期処理候補
3. 条件・資源交換・数量に応じた処理。既存の共通イベントに乗せられる可能性
4. 盤面操作・手動詳細選択・建築・畑・動物の再配置など新たな入力が必要な候補
5. 他プレイヤー、非公開手札、カード譲渡、カード種別兼用、特殊なターン処理を伴う候補

数字は強さ・難しさ（プレイ時）ではなく**実装の見積もり**。語句ベースの機械分類のため、個別レビューで頻繁に変わりうる。
CSVの `difficulty_reason` も暫定。カード原文との一対一照合は未着手。

## 4人戦・ドラフトの最低必要数
- 7-7ドラフト：職業28枚、小進歩28枚以上が必要。
- 10-7ドラフト：職業40枚、小進歩40枚以上が必要。
- 人数条件や禁止カードを除外した**実際に配れるカード数**で数える。実用上は各50枚以上を短期目標とし、効果が十分に異なるカードを優先する。
- A〜Eすべての実装より先に、4人戦10-7ドラフトの実用可能なカードプールを成立させる。

## カード実装の受け入れ
1. 出せる人数・費用・前提条件を独立したテストで検証。
2. 発動時点、強制/任意の違い、UIの手動選択、AIによる選択を照合。
3. 非公開手札・ドラフトの内容を相手の観測に漏らさない。
4. 保存/復元/ログ再演ハッシュが一致する。
5. 2〜4人、カードあり/なしを区分してCIで検証。
6. 日本語表示が人間に分かりやすいことをブラウザ操作テストで確認。

## 共通ロードマップ（遊びやすさ × AIの強さ）
1. **UI・日本語**：カード名・費用・効果概要、盤面直接操作、日本語エラー、手動14ラウンド。
2. **ブラウザ自動検証**：Playwrightで2人/4人・ドラフトあり/なし・カードあり/なしの基本操作を確認。失敗時はトレース、画像、エンジンログを取得する。1分CIの本体へ全件を詰めず、短い必須スモークと詳細な分離ジョブにする。
3. **ドラフト**：7-7、10-7同時、10-7配布選択を明確に区別。手札が非公開で、同一シードの再現・途中保存・AI選択が可能。
4. **カード追加**：難度1〜3の共通パターンを先に追加し、4人戦10-7の最低配布数を満たす。難度4〜5は個別Issueで設計・検証。
5. **AI**：ドラフトの価値評価、カード・行動の組み合わせ、非公開情報の再抽選、多人数の勝率評価を増強。ランダム/貪欲/評価関数/MCTSを先後・席順交代と固定シードで比較し、MCTS優位を未検証のまま主張しない。
