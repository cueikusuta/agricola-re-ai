## 第0章 目的・範囲・方法

### 0.1 依頼

`data/bga-card-specs/` のA帯（A001–A168）の仕様データについて、効果の読み（費用・前提・トリガー・対象・量・回数）を
ネット上の文献と1枚ずつ突き合わせ、食い違いを文献の根拠付きで修正する。文献で決まらないものは推測で埋めず、
日本語の文献要約を添えた人間への質問として残す。公式PDF・カード画像・カード原文は収録しない（`AGENTS.md` 6）。

### 0.3 文献と等級

| 出典 | 等級 | 使い方 |
|---|---|---|
| 2016年改訂版 Lookout 公式ルールブック | A | 用語と仕組みの原則（費用・前提・収穫・柵・改築） |
| `data/bga-card-specs/*.json`・`data/bga-card-base-ledger.csv` | B | 照合される側、費用・印刷点の台帳 |
| BGAアグリコラカード情報wiki 個別ページ（`https://agricola.cloudfree.jp/?p=NNNN`） | C | **主軸**。基本情報（No./区分/条件/コスト）、強化・品物・役割・勝利点、効果、寸評 |
| 同wiki 英語一覧 `/cardlist_en/`（id付き効果文）、日本語一覧 | C | 個別ページが別カードへ遷移する場合の同定 |
| 非公式コンピューディウム | D | 裁定・補足。推測の根拠には使わない |

各カードの効果説明は**自分の言葉による要約**で、原文の転載はしない。

### 0.4 判定の区分

- **一致**: 費用・前提・印刷点・トリガー・対象・量・回数が文献の読みと一致。
- **表現不足**: 大筋は一致するが、対象範囲・時点・上限が仕様に無い、または語彙で表せていない。
- **食い違い**: 仕様の読みと文献の読みが両立しない。
- **未確定**: 文献側に決め手が無い、または語彙・費用が未確定で保留が妥当。推測で埋めない。

### 0.5 ページ同定の注意

`bga.references[0].url` の `?p=` は301で転送され、現在は別カードを指すものがA帯に5枚ある
（A005, A010, A013, A023, A062）。これらは英語一覧（id・英語効果文つき）と日本語一覧（効果文）、
台帳の名称・費用で同定した。残り134枚は個別ページの「基本情報」表の No. で同定した。
