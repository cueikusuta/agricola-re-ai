## 第0章 目的・範囲・方法

### 0.1 依頼

`data/bga-card-specs/` のA帯（A001–A168）について、効果の読み（費用・前提・トリガー・対象・量・回数）を
ネット上の文献と1枚ずつ突き合わせ、食い違いを根拠付きで直す。文献で決まらないものは推測で埋めず、
日本語の文献要約を添えた質問として残す。公式PDF・カード画像・カード原文は収録しない（`AGENTS.md` 6）。

### 0.3 文献と等級

| 出典 | 等級 | 使い方 |
|---|---|---|
| 2016年改訂版 Lookout 公式ルールブック | A | 用語と仕組みの原則（費用・前提・収穫・柵・改築） |
| `data/bga-card-specs/*.json`・`data/bga-card-base-ledger.csv` | B | 照合される側、費用と印刷点の台帳 |
| BGAアグリコラカード情報wiki 個別ページ（`?p=NNNN`） | C | **主軸**。基本情報（No./区分/条件/コスト）、強化・品物・役割・勝利点、効果、寸評 |
| 同wiki 英語一覧 `/cardlist_en/`・日本語一覧 | C | 個別ページが別カードへ遷移する場合の同定 |
| 非公式コンピューディウム | D | 裁定・補足。推測の根拠には使わない |

効果の説明はすべて**自分の言葉による要約**で、原文は転載しない。

### 0.4 判定の区分

- **一致**: 費用・前提・印刷点・トリガー・対象・量・回数が文献の読みと一致。
- **表現不足**: 大筋は一致するが、対象範囲・時点・上限が仕様に無い、または語彙で表せていない。
- **食い違い**: 仕様の読みと文献の読みが両立しない。
- **未確定**: 文献側に決め手が無い、または語彙・費用が未確定で保留が妥当。

### 0.5 ページ同定の注意

`bga.references[0].url` の `?p=` は301転送され、現在は別カードを指すものがA帯に5枚ある
（A005, A010, A013, A023, A062）。これらは英語一覧（id付き効果文）・日本語一覧・台帳の名称と費用で同定した。
残りは個別ページの「基本情報」表の No. で同定した（1ページに人気記事ブロックが混在するため）。

### 0.6 仕様データの生成元という制約

`data/bga-card-specs/` は `scripts/build_bga_card_specs.py` の表から生成され、
`tests/test_bga_card_specs_builder.py` が「コミット済みファイル＝再生成結果」を要求する。
また各カードには `data/bga-card-tests/` のテスト契約がある。
このため本PRでは、**前提の補完・語彙名の修正・テスト契約と両立する効果の修正**だけを
ビルダー側に入れて再生成し、テスト契約が旧読みを前提にしている修正は
「保留（第4章）」として文献の読みと修正案を残した。推測でテスト契約を書き換えない。
