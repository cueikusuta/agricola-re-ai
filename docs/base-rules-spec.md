## 0. この文書について

### 0.1 目的と範囲

本書は『アグリコラ リバイズド』（2016年改訂版、Uwe Rosenberg、Lookout Games）の**ゲーム本体の基本ルール**を、実装がそのまま判定に使える粒度で記述する。対象範囲:

1. ゲームの準備とプレイヤー数ごとの違い（第1章）
2. ラウンドとステージの構成（第2章）
3. アクションスペースの一覧と各スペースの効果（第3章）
4. 家族と労働者の扱い（第4章）
5. 収穫フェイズの手順: 畑フェイズ・供給フェイズ・繁殖フェイズ（第5章）
6. 食料供給と物乞いの処理（第6章）
7. 家と改築（第7章）
8. 柵と小屋（厩）と農場の拡張（第8章）
9. 得点計算の全項目と同点の処理（第9章）

**対象外**: 個別の職業カード・小改善カードの効果（840枚規模のカード仕様は `docs/bga-card-specification.md` 以下の別体系）。ただしアクションスペースの解決に不可欠な**カードの基本機構**（配布・プレイ・費用・前提条件）は補遺（第10章）に最小限記述する。大改善10種は基本ルールの一部（食料変換・得点）として第3章・第6章・第9章で扱う。

**版の区別**: 正本は2016年改訂版（Revised Edition）のみ。2007年旧版（5人戦・E/I/Kデッキ等）および『アグリコラ：ファミリーバージョン』のルールは混在させない。ネット上の資料は旧版が多いため、本書の記述はすべて上記公式2PDFに基づき、既存文書との食い違いは第11章に記録する。

### 0.2 出典の優先順位

1. **公式ルールブック＋付録（2016改訂版・英語）** — ルールの正本。
2. `docs/rule-decisions.md` — 人間による公式照合済み解釈の記録（本書では「照合記録」と呼ぶ）。公式本文の文言が短い・画像依存の箇所を補完する。
3. `docs/design.md`・`docs/source-request.md` — プロジェクト設計メモ。基本設計の正本だが、ルール自体の記述が公式と食い違う場合は公式を正とし、第11章に記録する。
4. 実装コード（`src/`）— 本書の記述と相互検証したが、ルール決定の根拠としては扱わない（実装が公式と違えば実装側が修正対象）。

### 0.3 表記と読み方

- **引用**: `(RB p.N)` = 公式ルールブック N ページ、`(AP §N p.M)` = 公式付録の第 N 節・M ページ。ページ番号は公式英語PDFの印刷ページに従う（照合記録のページ引用と整合）。
- **【順序】** マーク: 処理順序が結果を変える、または順序が公式に固定されている箇所。
- **【例外】** マーク: 一般規則に対する例外。
- **【未確定 U#】** マーク: 公式で決まらない・解釈が割れる箇所。第12章の未確定一覧に対応する。**本書はこれらを推測で確定しない。**
- アクションスペース・カード・コンポーネントは**英語名を正キー**とし、日本語名は参考訳（公式日本語版の名称を保証しない）。用語対応は 0.4。
- 「できる/できない」は合法性、「してもよい」は任意、「しなければならない」は強制を意味する。
- 数量の端数: 本書で扱う得点・変換・収容はすべて整数。公式に端数処理（切り捨て等）が明示される箇所のみその旨書く。

## 1. ゲームの準備とプレイヤー数ごとの違い

### 1.1 コンポーネント（物理数量）

公式コンポーネント一覧 (RB p.1)。数量は**同梱コマの物理数**であり、ゲーム内の獲得上限ではない（1.2 の個数制限を参照）。

| 区分 | 内容 |
|---|---|
| 家畜 | 羊 18（白）・猪 15（黒）・牛 13（茶） |
| 建築資源 | 木材 30・粘土 24・葦 14・石 16 |
| 作物 | 穀物 24・野菜 16 |
| 食料マーカー | 「1食料」36・「5食料」8 |
| スタートプレイヤートークン | 1（黄） |
| プレイヤー色ごと（4色分） | 人物 5・厩 4・柵 15 |
| 農場ボード | 4枚（各 3行×5列＝15マス。うち2マスは印刷済みの木の部屋） |
| ゲームボード | 1枚＋拡張ボード2枚（得点早見表、および3/4人用アクションスペース面） |
| 大改善供給ボード | 1枚 |
| タイル | 木の部屋/畑タイル 23（両面）・粘土/石の部屋タイル 16（両面） |

| 提案マーカー | 3（黄、初心者紹介用） |
| カード120枚 | アクションスペースカード14（ステージ1〜6）・大改善10（赤）・職業48（黄）・小改善48（橙） |
| その他 | 得点メモ帳・仕分け袋10・ルールブック12p・付録12p |

### 1.2 個数制限と一般供給の有限性

**意図的な個数上限は、各プレイヤーの「人物5・厩4・柵15」だけ** (RB p.12 "Number of Components")。

- それ以外の共有コンポーネント（家畜・建築資源・作物・食料・部屋タイル等）が物理的に不足したら、品物タイルまたは代用品を使う。**ゲーム内の獲得数に上限を設けない。**
- 品物タイルは野菜・穀物・家畜・建築資源の代用を表せる（家畜は「4倍」表記も可能）。裏面は物乞いマーカー。
- 実装含意: 一般供給は有限リソースとしてモデル化しない。個人コマ（人物・厩・柵）の上限のみ不変条件として検査する。
- 注: 公式は品物タイルを「10枚」とする一方、代用内訳として「野菜2・穀物3・家畜4・建築資源5」を列挙しており、枚数の内訳記述に整合しない箇所がある。ルール影響はない（代用は不足時に随時行ってよい）。(RB p.1, p.12)

### 1.3 個人準備（全人数共通）

(RB p.2 "Setup")

1. プレイヤー色を1色選び、その色の**人物5・厩4・柵15**を受け取る。
2. 農場ボード1枚を取る。**印刷済みの2つの木の部屋に人物を1人ずつ**置く。残り3人（子息）と厩・柵は個人の供給に置く。
3. 使わない色のコマ・余りの農場ボードは箱に戻す。
4. 開始時の農場ボード: 使用済みマス2（木の部屋）、未使用マス13 (AP §5 p.5)。

### 1.4 共有準備

(RB p.2)

1. **タイル置き場**: 粘土/石の部屋タイルの山をゲームボード脇に置く。木の部屋/畑タイルの山を**2つに分け**、半分は木の部屋面を上、もう半分は畑面を上にして置く。
2. **ゲームボード**: 中央に置き、人数に応じた拡張ボードを正しい面で接続する（1.6）。
3. **大改善**: 赤い大改善10枚を供給ボードの所定位置に置く。かまど2枚（建築費 粘土2 / 粘土3）と調理場2枚（粘土4 / 粘土5）はそれぞれ2枚ある（第6章・第10章）。
4. **スタートプレイヤー**: 無作為に決める。**スタートプレイヤーは食料2、他の各プレイヤーは食料3**を受け取る。
   - 実装含意: 無作為決定はシード付き乱数で行い、ログに記録する（`docs/design.md` M1確定仕様。公式は「無作為」とだけ定める）。
5. **小改善**: 橙48枚をシャッフルし、各プレイヤーに**7枚**ずつ配る（手札）。
6. **職業**: 黄カード左端の人数記号でフィルタする — `[1+]` = 1〜4人用、`[3+]` = 3〜4人用、`[4]` = 4人用。現在の人数で使わないカードは箱に戻し、残りをシャッフルして各プレイヤーに**7枚**ずつ配る。
7. **アクションスペースカード**: 14枚をシャッフルし、**裏面のステージ番号で6つの山に分類**する。下からステージ6→5→4→3→2→1の順に重ね、**ステージ1の山が最も上**になるように1つの札束にする。同一ステージ内の順序はシャッフル由来の無作為順。【順序】この札束の上から毎ラウンド1枚ずつ公開される（第2章）。
8. **一般供給**: 家畜（羊・猪・牛）・建築資源（木・粘土・葦・石）・作物（穀物・野菜）・食料マーカーをすべて手の届く所に置く。
9. **品物タイル**（裏面＝物乞いマーカー）は脇に置いておく（必要時のみ使用）。
10. **バリアントタイル・副業タイル・提案マーカー**: 基本ゲームでは使わない (RB p.2)。使用は任意（1.7・第3章）。

**手札はゲーム中に追加ドローしない。** 開始時の7+7枚のみで戦う (RB p.11)。手札にある間、カードはゲームに一切影響しない。

### 1.5 農場ボードの構造

(AP §5 "Farm and Farmyard Board" p.5)

- 15マス＝3行×5列。開始時2マスは木の部屋（印刷済み）。残り13マスは自由に開発できる。
- **隣接**: 農場マス同士は、同じ柵スペースを挟んで直交（辺を共有）する場合に隣接するという。斜め隣接は隣接ではない。柵は農場マスの間またはボード外周の「柵スペース」に建てる。
- **使用済みマス**: 部屋タイル・畑タイルが載っている、柵で（直接・間接に）囲われている、厩が建っている、のいずれかで「使用済み」。空マス、または（カード由来の）品物・家畜だけが載っているマスは「未使用」。開始時は使用済み2・未使用13。
- 部屋の材質は「家」全体の属性（木の家→粘土の家→石の家）。改築は家全体に対して行う（第7章）。

### 1.6 プレイヤー数ごとの違い（2/3/4人）

人数で変わるのは**アクションスペースの構成・職業コスト・職業カードのプール**であり、農場ボード・ラウンド数・収穫時期・得点規則は変わらない (RB p.2, p.11; AP §6 p.6-8; `docs/design.md` M4)。

| 項目 | 2人 | 3人 | 4人 |
|---|---|---|---|
| 常設スペース | 基本10種（0.5表の「全人数」） | 基本＋3人用4種 | 基本＋4人用6種 |
| 追加スペース（拡張ボード） | なし | Grove（+2木）, Hollow（+1粘土）, Resource Market（葦1**または**石1＋食料1）, Lessons（職業コスト2食料） | Copse（+1木）, Grove（+2木）, Hollow（+2粘土）, Resource Market（葦1**かつ**石1＋食料1）, Lessons（最初の2枚は各1食料、以降2食料）, Traveling Players（+1食料・累積） |
| 授業（基本 Lessons）の職業コスト | 最初の1枚無料、以降1食料 | 同左 | 同左 |
| 職業カードプール | `[1+]` のみ | `[1+]`＋`[3+]` | `[1+]`＋`[3+]`＋`[4]` |
| 開始食料 | スタートプレイヤー2 / 他3 | 同左 | 同左 |
| バリアントタイル（任意） | 大タイル4択（第3章） | 小タイル2択 | 小タイル2択 |

- 3人用と4人用は同じ拡張ボードの表裏で切り替える（「in one case—action spaces for the multi-player game」RB p.1）。2人戦ではアクションスペース追加面を使わない。
- 【例外】4人戦の Traveling Players（旅芸人）は4人専用 (RB p.9)。
- 各スペースの詳細効果は第3章。

### 1.7 バリアント（公式が認める任意ルール）

基本ゲームの必須ルールではない。プロジェクトでの採否は `docs/design.md` に従う。

1. **手札なし初心者バリアント** (AP §1 p.1): 職業・小改善の手札を使わない。この場合、**集会所（Meeting Place）を「毎ラウンド食料1が累積する累積スペース」に変更する**。さらに（特に4人戦では）副業タイルの追加が推奨される（パン焼きの重要性が増すため）。
   - 【未確定 U7】この変更後も集会所がスタートプレイヤー権の取得を兼ねるかは公式本文に明記がない（第12章）。
   - プロジェクト: M1の基準モードは本バリアント（`docs/design.md`）。副業タイルは**実装しない**（確定方針。公式の「推奨」との差異は第11章 D6）。
2. **追加アクションスペース（バリアントタイル）** (AP §6 p.8): 準備時に任意で導入。2人用は4択、3/4人用は2択。詳細は第3章。プロジェクトの初期設定は OFF（`docs/design.md` M1確定仕様。公式は「任意」と定めるのみで、初期値はプロジェクト決定）。
3. **副業（Side Job）** (AP §1 p.1): 手札なしゲーム用。「厩1つを木材1で建設」および/または「パン焼き」。基本ゲームでは使わない。プロジェクトは実装しない。
4. **ドラフト等** (AP §7 p.8-9): 手札の配布をドラフトにする变型（7枚→1枚選んで左へ渡す、等）。複数方式が公式付録に列挙される。プロジェクトのドラフト工程（M11）は `docs/draft-protocol-m11.md` が正本であり、本書の範囲外。
5. **ソロゲーム** (RB p.12): 1.8 を参照。
6. キャンペーン・チーム戦・ハウスルール (AP §7-8): 基本ルールの範囲外。参照のみ。

### 1.8 ソロゲーム（1人）の違い

(RB p.12 "Solo Game")

ソロは**2人戦ルールを1人で順に手番を進める**方式で、以下が異なる:

- 開始食料は **0**。
- 供給フェイズで**成人は食料3**を要求される（新生児は1のまま）。
- 林（Forest）には毎ラウンド**木材2**（3ではなく）が補充される。
- 渡りカードは左のプレイヤーへ渡す代わりに**ゲームから除去**する。
- 任意で、手札カードとアクションスペースカードの出現順を選んでよい。
- ソロキャンペーン（目標得点 50→55→59→62→64→65→66→67、職業の永続化等）は AP §8 p.10。本書の範囲外（参照のみ）。

プロジェクトの実装対象は2〜4人戦であり、ソロは仕様参照情報として記述する。

## 2. ラウンドとステージの構成

### 2.1 全体構造

- ゲームは**14ラウンド**で構成される (RB p.3 "A game of Agricola is played over 14 rounds")。
- 各ラウンドは**4つのフェイズ**を順に実行する (RB p.6 "Course of Play"):
  1. **準備フェイズ** (Preparation Phase)
  2. **労働フェイズ** (Work Phase)
  3. **帰宅フェイズ** (Returning Home Phase)
  4. **収穫** (Harvest) — 実施ラウンドのみ
- 【順序】フェイズは固定順であり、入れ替えられない。前フェイズが完了してから次へ進む。
- 収穫があるのは**ラウンド4・7・9・11・13・14の終了時**（6回）(RB p.9)。ゲームボード上の収穫アイコンで示される (RB p.6)。
- 最終ラウンド（14）の収穫の後に**得点計算**を行い、ゲーム終了 (RB p.12)。

### 2.2 ステージとアクションスペースカードの登場

(RB p.6 "Preparation Phase"; AP §6 p.6-8)

アクションスペースカード14枚は6ステージに分かれ、準備時に6つの山へ分類されて1つの札束に積まれる（1.4-7）。**毎ラウンド、札束の上から1枚を引き、そのラウンド番号のラウンドスペースに置く。** これにより新しいアクションスペースが解禁される。

| ステージ | カード | 登場ラウンド | 備考 |
|---|---|---|---|
| 1 | Major Improvement, Fencing, Grain Utilization, Sheep Market | 1〜4 | いずれも2人戦以上で使用。Sheep Market は登場が「ラウンド1〜4の間」と表現される (RB p.8) |
| 2 | Basic Wish for Children, House Redevelopment, Western Quarry | 5〜7 | 家族増員（部屋必須）と改築が解禁。RB p.7「家族増員はラウンド5・6・7のいずれかで可能になる」 |
| 3 | Vegetable Seeds, Pig Market | 8〜9 | RB p.9「野菜はラウンド8か9に登場」、RB p.8「Pig Market はラウンド8か9」 |
| 4 | Cattle Market, Eastern Quarry | 10〜11 | RB p.8「Cattle Market はラウンド10か11」 |
| 5 | Urgent Wish for Children, Cultivation | 12〜13 | RB p.7「ラウンド12か13に Urgent Wish for Children が登場」 |
| 6 | Farm Redevelopment | 14 | RB p.7「最終ラウンドに2つ目の改築スペースが登場」 |

**ステージ内の順序は固定されない**（シャッフル由来）。したがって「何ラウンド目にどのスペースが出るか」は非公開情報であり、AI観測からは除外する（`docs/design.md` 設計原則2）。

- 【例外】ラウンドスペースの番号とカード裏面のステージ番号は一致しない（例: ステージ2のカード3枚はラウンド5・6・7のどれにでも置かれ得る）。実装上は「ステージNのカードはラウンド範囲 [start_N, end_N] のいずれかに配置」という制約で表現できる。
- 表の「登場ラウンド」欄は、公式本文が個別に言及した範囲（RB p.7-9）と、ステージ番号からの導出（1ステージ＝連続する番号帯）を併記したもの。導出のみの箇所は RB に明示がない。

### 2.3 準備フェイズの手順

(RB p.6; AP §5 "Preparation phase" p.4)

**【順序】以下の順に実行する。順序は結果を変える。**

1. **アクションスペースカードの公開**: 山の上から1枚引き、現在ラウンド番号のラウンドスペースに置く（2.2）。
2. **ラウンドスペース上の品物の取得**: そのラウンドスペースに（カード効果で）置かれていた品物を、置いた本人が受け取る。例: 井戸（Well）は建設時に以後5ラウンド分のラウンドスペースへ食料1を置く (RB p.10)。
   - この段階で、当該ラウンドスペースはまだアクションスペースカードに覆われていない場合がある（井戸の記述「まだアクションスペースカードで覆われていないラウンドスペース」RB p.10）。覆われた後の処理は【未確定 U5】（第12章）。
3. **累積スペースへの補充**: 黄土色の矢印が描かれた各アクションスペース（累積スペース）へ、図示された数量の品物を置く。**前ラウンドからの残りがあっても、その上に加える**（置き換えではない）。
   - 例: 林（Forest）は毎ラウンド木材3を追加する。前ラウンドの残り3木材があれば合計6木材になる (RB p.6)。

**準備フェイズに関する一般規則** (AP §5 "Preparation phase"):

- ラウンドスペースから受け取る品物は**辞退できない**（「You may not decline goods that you would get from a round space」）。
- 品物と何かを**交換**する形の効果は辞退できる。辞退した場合、差し出した側のコマ（厩・柵・人物）は供給へ、受け取るはずだったタイル・品物は一般供給へ戻す。**辞退した交換を後から行うことはできない。**
- 準備フェイズ中に複数の品物を得る場合、**受け取る順序は自由**。
- カードが「ラウンド開始前 (before the start of the round)」に言及する場合、それは準備フェイズ開始の直前を指す。したがって**ラウンドスペースからの品物受領より前に発動する**。【順序】

### 2.4 労働フェイズの手順

(RB p.6 "Work Phase"; AP §5 "Work phase" p.4)

1. **スタートプレイヤーから時計回り**に、各プレイヤーが**人物をちょうど1人**アクションスペースに置き、そのスペースの効果を実行する。
2. 全プレイヤーが持ち駒（`in play` の人物）を置き終えるまで繰り返す。
3. **占有**: 1つのアクションスペースは**1ラウンドにつき1人しか使えない**。占有されたスペースはそのラウンドの残り使用不可。
4. **人物の回収は全員が置き終えるまで行わない** (RB p.3)。
5. 人物が尽きたプレイヤーは**飛ばす**。残っているプレイヤーだけで時計回りを続ける (RB p.6 脚注)。
   - 【順序】人物数が異なる場合、ターン順は「残っている人の間での時計回り」であり、固定の席順巡回ではない。
6. **即時実行**: 置いた直後にそのスペースの効果を実行する（後回しにできない）。
7. **少なくとも1つの効果を実行しなければならない**。「スペースを使うが効果は取らない」は不可 (RB p.6; AP §6 p.6)。
   - 【例外】カードが「代替アクション (replacement action)」を認める場合、その代替を取れば使用可能 (AP §6 p.6; AP §5 "Placing a person" p.5)。
8. **複数効果のあるスペース**: 表記が **"and/or"** なら任意順・任意選択、**"and afterward"** なら**第1効果を必ず実行した後にのみ**第2効果を実行できる (RB p.6 "Some permanent action spaces...")。【順序】
   - "and/or" の典型: 農場拡張（部屋建設 and/or 厩建設）、穀物利用（種まき and/or パン焼き）、耕作（開墾 and/or 種まき）。
   - "and afterward" の典型: 集会所（スタートプレイヤー取得→小改善）、基本的な子供の願い（家族増員→小改善）、家の改築（改築→大/小改善）、農場の再開発（改築→柵建設）。
9. **占有の解除**: 労働フェイズ中に最後の人物がそのスペースから取り除かれた場合、そのスペースは**未占有とみなされ、他のプレイヤーが再使用できる** (AP §5 "Work phase" p.4)。
   - 注: 通常は帰宅フェイズまで人物は動かないため、これはカード効果による例外的な移動を指す。
10. **同一スペースへの複数人物**: カードが認める場合のみ、同一または別プレイヤーの複数人物が同じスペースに置かれ得る。どの人物が許されるかはカードごとに読む (AP §5 "Work phase" p.4)。

### 2.5 帰宅フェイズ

(RB p.6 "Returning Home Phase")

**全員が人物を置き終えたら、全人物を家（部屋）へ戻す。**

- 配置された人物はすべて手元（家）に戻る。次ラウンドの労働フェイズで再び使用できる。
- 各人物は**1部屋につき1人**を占める (RB p.3, p.7)。帰宅時に家の部屋数より人物が多い状態は原則として生じない（家族増員の条件が「部屋数 > 人物数」であるため）。ただし「部屋なしの家族増員」を使った場合は部屋不足が起こり得る（第4章）。
- 【未確定 U6】帰宅フェイズに「戻す」以外の処理（優劣判定や選別）があるかは公式本文に記述がない。本書は「全人物を家へ戻すだけ」と解釈する（第12章）。

### 2.6 収穫の実施判定と、ラウンド進行の不変条件

- **【順序】** 収穫は帰宅フェイズの後に実行する。収穫のあるラウンドでは、帰宅→収穫の順を守る。
- ラウンド4・7・9・11・13・14の終了時に収穫（2.1）。
- 最終ラウンド14の収穫後に得点計算（第9章）。
- **不変条件（実装が毎ラウンド検査すべき項目）**:
  - 使用済みアクションスペースは同一ラウンド内で再使用不可（2.4-3）。ただし2.4-9の例外あり。
  - 各プレイヤーの人物は最大5。手元＋配置済みの合計が5を超えない（1.2）。
  - ラウンド番号は1〜14。14を超えて進まない。
  - 各ラウンドで公開されるアクションスペースカードはちょうど1枚。14ラウンドで14枚すべてが公開される。
  - 累積スペースの品物は、ラウンドをまたいで保持される（2.3-3）。使用時に全量取得する（第3章）。

### 2.7 ラウンド進行の状態遷移（実装向け要約）

```
for round in 1..=14:
    # 準備フェイズ
    reveal(action_space_card_for_round(round))
    for each player with goods on round_space[round]: give(those goods, undeclinable)
    for each accumulation_space: add(depicted amount)   # keep leftovers
    # 労働フェイズ
    turn = starting_player
    while any player has unplaced people:
        if turn has unplaced people: place one person; resolve(space)
        turn = next player clockwise with unplaced people
    # 帰宅フェイズ
    return all placed people home; assign newborn to own room
    # 収穫（該当ラウンドのみ）
    if round in {4,7,9,11,13,14}:
        field_phase(); feeding_phase(); breeding_phase()
# 得点計算
score_all_players(); resolve_ties()
```

- 【順序】上記疑似コードの各ブロック内順序は 2.3〜2.6 の記述に従う。特に準備フェイズの3手順（カード公開→ラウンドスペース品物→累積補充）は入れ替えない。
