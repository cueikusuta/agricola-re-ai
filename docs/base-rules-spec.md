## 0. この文書について

### 0.1 目的と範囲

本書は『アグリコラ リバイズド』（2016年改訂版、Uwe Rosenberg、Lookout Games）の**ゲーム本体の基本ルール**を、実装がそのまま判定に使える粒度で記述する。対象範囲:

1. ゲームの準備とプレイヤー数ごとの違い（第1章）
2. ラウンドとステージの構成（第2章）
3. アクションスペースの一覧と各スペースの効果（第3章）
4. 家族と労働者の扱い（第4章）
5. 収穫フェイズの手順: 畑フェイズ・供給フェイズ・繁殖フェイズ（第5章）
6. 食料供給と物乞いの処理（第6章）
7. 家と改築（第7章）
8. 柵と小屋（厩）と農場の拡張（第8章）
9. 得点計算の全項目と同点の処理（第9章）

**対象外**: 個別の職業カード・小改善カードの効果（840枚規模のカード仕様は `docs/bga-card-specification.md` 以下の別体系）。ただしアクションスペースの解決に不可欠な**カードの基本機構**（配布・プレイ・費用・前提条件）は補遺（第10章）に最小限記述する。大改善10種は基本ルールの一部（食料変換・得点）として第3章・第6章・第9章で扱う。

**版の区別**: 正本は2016年改訂版（Revised Edition）のみ。2007年旧版（5人戦・E/I/Kデッキ等）および『アグリコラ：ファミリーバージョン』のルールは混在させない。ネット上の資料は旧版が多いため、本書の記述はすべて上記公式2PDFに基づき、既存文書との食い違いは第11章に記録する。

### 0.2 出典の優先順位

1. **公式ルールブック＋付録（2016改訂版・英語）** — ルールの正本。
2. `docs/rule-decisions.md` — 人間による公式照合済み解釈の記録（本書では「照合記録」と呼ぶ）。公式本文の文言が短い・画像依存の箇所を補完する。
3. `docs/design.md`・`docs/source-request.md` — プロジェクト設計メモ。基本設計の正本だが、ルール自体の記述が公式と食い違う場合は公式を正とし、第11章に記録する。
4. 実装コード（`src/`）— 本書の記述と相互検証したが、ルール決定の根拠としては扱わない（実装が公式と違えば実装側が修正対象）。

### 0.3 表記と読み方

- **引用**: `(RB p.N)` = 公式ルールブック N ページ、`(AP §N p.M)` = 公式付録の第 N 節・M ページ。ページ番号は公式英語PDFの印刷ページに従う（照合記録のページ引用と整合）。
- **【順序】** マーク: 処理順序が結果を変える、または順序が公式に固定されている箇所。
- **【例外】** マーク: 一般規則に対する例外。
- **【未確定 U#】** マーク: 公式で決まらない・解釈が割れる箇所。第12章の未確定一覧に対応する。**本書はこれらを推測で確定しない。**
- アクションスペース・カード・コンポーネントは**英語名を正キー**とし、日本語名は参考訳（公式日本語版の名称を保証しない）。用語対応は 0.4。
- 「できる/できない」は合法性、「してもよい」は任意、「しなければならない」は強制を意味する。
- 数量の端数: 本書で扱う得点・変換・収容はすべて整数。公式に端数処理（切り捨て等）が明示される箇所のみその旨書く。

## 1. ゲームの準備とプレイヤー数ごとの違い

### 1.1 コンポーネント（物理数量）

公式コンポーネント一覧 (RB p.1)。数量は**同梱コマの物理数**であり、ゲーム内の獲得上限ではない（1.2 の個数制限を参照）。

| 区分 | 内容 |
|---|---|
| 家畜 | 羊 18（白）・猪 15（黒）・牛 13（茶） |
| 建築資源 | 木材 30・粘土 24・葦 14・石 16 |
| 作物 | 穀物 24・野菜 16 |
| 食料マーカー | 「1食料」36・「5食料」8 |
| スタートプレイヤートークン | 1（黄） |
| プレイヤー色ごと（4色分） | 人物 5・厩 4・柵 15 |
| 農場ボード | 4枚（各 3行×5列＝15マス。うち2マスは印刷済みの木の部屋） |
| ゲームボード | 1枚＋拡張ボード2枚（得点早見表、および3/4人用アクションスペース面） |
| 大改善供給ボード | 1枚 |
| タイル | 木の部屋/畑タイル 23（両面）・粘土/石の部屋タイル 16（両面） |

| 提案マーカー | 3（黄、初心者紹介用） |
| カード120枚 | アクションスペースカード14（ステージ1〜6）・大改善10（赤）・職業48（黄）・小改善48（橙） |
| その他 | 得点メモ帳・仕分け袋10・ルールブック12p・付録12p |

### 1.2 個数制限と一般供給の有限性

**意図的な個数上限は、各プレイヤーの「人物5・厩4・柵15」だけ** (RB p.12 "Number of Components")。

- それ以外の共有コンポーネント（家畜・建築資源・作物・食料・部屋タイル等）が物理的に不足したら、品物タイルまたは代用品を使う。**ゲーム内の獲得数に上限を設けない。**
- 品物タイルは野菜・穀物・家畜・建築資源の代用を表せる（家畜は「4倍」表記も可能）。裏面は物乞いマーカー。
- 実装含意: 一般供給は有限リソースとしてモデル化しない。個人コマ（人物・厩・柵）の上限のみ不変条件として検査する。
- 注: 公式は品物タイルを「10枚」とする一方、代用内訳として「野菜2・穀物3・家畜4・建築資源5」を列挙しており、枚数の内訳記述に整合しない箇所がある。ルール影響はない（代用は不足時に随時行ってよい）。(RB p.1, p.12)

### 1.3 個人準備（全人数共通）

(RB p.2 "Setup")

1. プレイヤー色を1色選び、その色の**人物5・厩4・柵15**を受け取る。
2. 農場ボード1枚を取る。**印刷済みの2つの木の部屋に人物を1人ずつ**置く。残り3人（子息）と厩・柵は個人の供給に置く。
3. 使わない色のコマ・余りの農場ボードは箱に戻す。
4. 開始時の農場ボード: 使用済みマス2（木の部屋）、未使用マス13 (AP §5 p.5)。

### 1.4 共有準備

(RB p.2)

1. **タイル置き場**: 粘土/石の部屋タイルの山をゲームボード脇に置く。木の部屋/畑タイルの山を**2つに分け**、半分は木の部屋面を上、もう半分は畑面を上にして置く。
2. **ゲームボード**: 中央に置き、人数に応じた拡張ボードを正しい面で接続する（1.6）。
3. **大改善**: 赤い大改善10枚を供給ボードの所定位置に置く。かまど2枚（建築費 粘土2 / 粘土3）と調理場2枚（粘土4 / 粘土5）はそれぞれ2枚ある（第6章・第10章）。
4. **スタートプレイヤー**: 無作為に決める。**スタートプレイヤーは食料2、他の各プレイヤーは食料3**を受け取る。
   - 実装含意: 無作為決定はシード付き乱数で行い、ログに記録する（`docs/design.md` M1確定仕様。公式は「無作為」とだけ定める）。
5. **小改善**: 橙48枚をシャッフルし、各プレイヤーに**7枚**ずつ配る（手札）。
6. **職業**: 黄カード左端の人数記号でフィルタする — `[1+]` = 1〜4人用、`[3+]` = 3〜4人用、`[4]` = 4人用。現在の人数で使わないカードは箱に戻し、残りをシャッフルして各プレイヤーに**7枚**ずつ配る。
7. **アクションスペースカード**: 14枚をシャッフルし、**裏面のステージ番号で6つの山に分類**する。下からステージ6→5→4→3→2→1の順に重ね、**ステージ1の山が最も上**になるように1つの札束にする。同一ステージ内の順序はシャッフル由来の無作為順。【順序】この札束の上から毎ラウンド1枚ずつ公開される（第2章）。
8. **一般供給**: 家畜（羊・猪・牛）・建築資源（木・粘土・葦・石）・作物（穀物・野菜）・食料マーカーをすべて手の届く所に置く。
9. **品物タイル**（裏面＝物乞いマーカー）は脇に置いておく（必要時のみ使用）。
10. **バリアントタイル・副業タイル・提案マーカー**: 基本ゲームでは使わない (RB p.2)。使用は任意（1.7・第3章）。

**手札はゲーム中に追加ドローしない。** 開始時の7+7枚のみで戦う (RB p.11)。手札にある間、カードはゲームに一切影響しない。

### 1.5 農場ボードの構造

(AP §5 "Farm and Farmyard Board" p.5)

- 15マス＝3行×5列。開始時2マスは木の部屋（印刷済み）。残り13マスは自由に開発できる。
- **隣接**: 農場マス同士は、同じ柵スペースを挟んで直交（辺を共有）する場合に隣接するという。斜め隣接は隣接ではない。柵は農場マスの間またはボード外周の「柵スペース」に建てる。
- **使用済みマス**: 部屋タイル・畑タイルが載っている、柵で（直接・間接に）囲われている、厩が建っている、のいずれかで「使用済み」。空マス、または（カード由来の）品物・家畜だけが載っているマスは「未使用」。開始時は使用済み2・未使用13。
- 部屋の材質は「家」全体の属性（木の家→粘土の家→石の家）。改築は家全体に対して行う（第7章）。

### 1.6 プレイヤー数ごとの違い（2/3/4人）

人数で変わるのは**アクションスペースの構成・職業コスト・職業カードのプール**であり、農場ボード・ラウンド数・収穫時期・得点規則は変わらない (RB p.2, p.11; AP §6 p.6-8; `docs/design.md` M4)。

| 項目 | 2人 | 3人 | 4人 |
|---|---|---|---|
| 常設スペース | 基本10種（0.5表の「全人数」） | 基本＋3人用4種 | 基本＋4人用6種 |
| 追加スペース（拡張ボード） | なし | Grove（+2木）, Hollow（+1粘土）, Resource Market（葦1**または**石1＋食料1）, Lessons（職業コスト2食料） | Copse（+1木）, Grove（+2木）, Hollow（+2粘土）, Resource Market（葦1**かつ**石1＋食料1）, Lessons（最初の2枚は各1食料、以降2食料）, Traveling Players（+1食料・累積） |
| 授業（基本 Lessons）の職業コスト | 最初の1枚無料、以降1食料 | 同左 | 同左 |
| 職業カードプール | `[1+]` のみ | `[1+]`＋`[3+]` | `[1+]`＋`[3+]`＋`[4]` |
| 開始食料 | スタートプレイヤー2 / 他3 | 同左 | 同左 |
| バリアントタイル（任意） | 大タイル4択（第3章） | 小タイル2択 | 小タイル2択 |

- 3人用と4人用は同じ拡張ボードの表裏で切り替える（「in one case—action spaces for the multi-player game」RB p.1）。2人戦ではアクションスペース追加面を使わない。
- 【例外】4人戦の Traveling Players（旅芸人）は4人専用 (RB p.9)。
- 各スペースの詳細効果は第3章。

### 1.7 バリアント（公式が認める任意ルール）

基本ゲームの必須ルールではない。プロジェクトでの採否は `docs/design.md` に従う。

1. **手札なし初心者バリアント** (AP §1 p.1): 職業・小改善の手札を使わない。この場合、**集会所（Meeting Place）を「毎ラウンド食料1が累積する累積スペース」に変更する**。さらに（特に4人戦では）副業タイルの追加が推奨される（パン焼きの重要性が増すため）。
   - 【未確定 U7】この変更後も集会所がスタートプレイヤー権の取得を兼ねるかは公式本文に明記がない（第12章）。
   - プロジェクト: M1の基準モードは本バリアント（`docs/design.md`）。副業タイルは**実装しない**（確定方針。公式の「推奨」との差異は第11章 D6）。
2. **追加アクションスペース（バリアントタイル）** (AP §6 p.8): 準備時に任意で導入。2人用は4択、3/4人用は2択。詳細は第3章。プロジェクトの初期設定は OFF（`docs/design.md` M1確定仕様。公式は「任意」と定めるのみで、初期値はプロジェクト決定）。
3. **副業（Side Job）** (AP §1 p.1): 手札なしゲーム用。「厩1つを木材1で建設」および/または「パン焼き」。基本ゲームでは使わない。プロジェクトは実装しない。
4. **ドラフト等** (AP §7 p.8-9): 手札の配布をドラフトにする变型（7枚→1枚選んで左へ渡す、等）。複数方式が公式付録に列挙される。プロジェクトのドラフト工程（M11）は `docs/draft-protocol-m11.md` が正本であり、本書の範囲外。
5. **ソロゲーム** (RB p.12): 1.8 を参照。
6. キャンペーン・チーム戦・ハウスルール (AP §7-8): 基本ルールの範囲外。参照のみ。

### 1.8 ソロゲーム（1人）の違い

(RB p.12 "Solo Game")

ソロは**2人戦ルールを1人で順に手番を進める**方式で、以下が異なる:

- 開始食料は **0**。
- 供給フェイズで**成人は食料3**を要求される（新生児は1のまま）。
- 林（Forest）には毎ラウンド**木材2**（3ではなく）が補充される。
- 渡りカードは左のプレイヤーへ渡す代わりに**ゲームから除去**する。
- 任意で、手札カードとアクションスペースカードの出現順を選んでよい。
- ソロキャンペーン（目標得点 50→55→59→62→64→65→66→67、職業の永続化等）は AP §8 p.10。本書の範囲外（参照のみ）。

プロジェクトの実装対象は2〜4人戦であり、ソロは仕様参照情報として記述する。
