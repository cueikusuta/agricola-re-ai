**判定: `hold`**（pass 17 / fail 0 / hold 4）。データ由来の検査はすべて pass し、**M8 証拠に依存する4項目が未提出のため合格にはしない**。合成データによる合格ではなく、実試合の成果物で判定した記録である。

## 2. データ分割（Manifest）

`dataset_split manifest` で、学習データ1,000試合を seed 範囲で3分割した。

| split | seed範囲 | 試合数 | 学習サンプル |
|---|---|---:|---:|
| train | 920000–920249 | 250 | 20,183 |
| validation | 920250–920399 | 150 | 12,059 |
| test | 920400–920999 | 600 | 48,559 |
| 合計 | 920000–920999 | **1,000** | **80,801** |

- 評価 seed は 920500–920999 で、**ロックされた test 範囲（920400–920999）の内側**にある。
- 重複 seed・初期状態の分割間共有・provenance混在・非公開情報の混入は `build_manifest` が拒否する。`usable: true`。

Manifest 全体は 93 KB のため本PRには**保存していない**。再生成コマンドは 5節。

## 3. G0 判定結果

```json

  "dataset_episodes": 1000, "dataset_training_samples": 80801,
  "evaluated_modes": ["cardless_2p"] }
```

データから再計算した検査（すべて **pass**）:

| 検査 | 実測 |
|---|---|

| `provenance_uniform` | engine `0.1.0` / rules `agricola-revised-2016-beginner` / cards `none` / code_sha 1値 |

| `verified_card_condition` | `none` |
| `evidence_schema` | v2 |
| `evaluation_mode_conditions` | dataset の条件（cards `none`, players 2）と一致 |
| `evaluation_matches_digest` | 4シャード連結の SHA-256 が一致（`ad12eef4…61aa`） |

| `evaluation_block_completeness` | 500ブロック × 2席 × 2arm、未知armなし |

**`hold`（4件）の理由**: `m8_rule_evidence` / `m8_legal_api_evidence` / `evaluation_observation_noninterference` / `evaluation_ci_reproducible`。これらは matches から再計算できず、**hash 束縛された checks ファイル**（`checks_evidence.schema_version=2`、`code_sha` と `matches_sha256` を含む）を提出した場合にのみ判定される。本セッションでは M8-1（公式ルール期待結果）・M8-2（合法詳細API）の証拠を用意できないため、**偽って true にせず未提出のまま hold とした**。

## 4. 成果物

- `evidence.json`: モード・試合数ではなく、**matches 4ファイルの参照と SHA-256** のみを持つ（v2形式）。試合数はゲートが行から再計算する。
- `report.json`: 上記 G0 レポート全文（checks 17 pass / 4 hold）。
- `episodes-report.json`: `episode_inspect` によるデータ健康診断（1,000件・重複0・破損0・provenance 1値）。

評価 matches そのもの（4シャード × 500行）は Actions Artifact `shard-0..3` にあり、リポジトリには含めない（サイズと再現手順で代替）。

## 5. 再実行手順

```sh
# 1. 学習データ（Actions）
gh workflow run episode-data.yml -f episodes=1000 -f players=2 -f shards=4 \
  -f policy=eval -f seed_start=920000 -f cards=false -f extra=false
# 2. 評価データ（Actions、各arm 1,000試合 = 500 blocks x 2 seats）
gh workflow run paired-eval.yml -f players=2 -f blocks=500 -f seed_start=920500 \
  -f candidate=eval -f baseline=random -f opponent=greedy \
  -f cards=none -f search_mode=simulation-capped -f decision_budget_ms=0
# 3. 分割 Manifest と G0
./target/release/dataset_split manifest --in episodes.jsonl --out manifest.json \
  --train 920000:920249 --validation 920250:920399 --test 920400:920999
python scripts/g0_evidence.py --mode cardless_2p --players 2 --card-mode none \
  --matches shard-0.jsonl --matches shard-1.jsonl --matches shard-2.jsonl \
  --matches shard-3.jsonl --artifact-url <run URL> --code-sha <sha> --out evidence.json
./target/release/dataset_split g0 --manifest manifest.json \
  --dataset-report episodes-report.json --evidence evidence.json --out report.json
```

## 6. G0 を `pass` にするために残っているもの

1. **M8-1 の公式ルール証拠**（期待結果テストの実行記録、#108）。
2. **M8-2 の合法詳細API証拠**（不正手拒否・`SimpleDetails` 外の合法手受理、#109）。
3. **観測非干渉の証拠**（`tests/m8_observation_noninterference` 系を、この評価条件で実行した記録）。
4. **CI 再現性の証拠**（同一 seed ブロックでの再実行一致）。
5. これらを束縛した checks ファイル（`schema_version=2`、`code_sha`、`matches_sha256`）。

**本判定は `hold` であり、G0 合格ではない。** 大規模学習は開始しない（`docs/ai-experiments-m12-m14.md` 6節）。
