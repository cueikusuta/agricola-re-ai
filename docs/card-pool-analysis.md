## 第0章 この文書の位置づけと方法

### 0.1 目的

PR #377（全840枚の分類確定版）と仕様データ `data/bga-card-specs/` をもとに、カードプールの分布を
読み取り専用で集計・分析する。観点は (1) 帯・種類・効果の型（トリガー）の分布、(2) 費用と印刷点の分布、
(3) 実装段階ごとの枚数と未実装残りの偏り、(4) 他プレイヤーが関わる効果の割合、(5) 偏りから言えること。
第5章では**事実と意見を明示的に分離**する。意見は分析者の見解であり、プロジェクトの決定・公式ルール解釈ではない。
ルール判断を要する事項は #377 第7章の質問（MQ-01〜17）に委ね、本文書では新解釈を作らない。

### 0.3 定義

- **帯（デッキ）**: A〜E の5デッキ、各168枚。**帯内** = #370 の分類対象636枚（A/C/D/E の 001〜069・121〜168、
  B の 001〜168）。**帯外** = A/C/D/E の 070〜120 の204枚。Bデッキに帯外は無い（#377 §1.2）。
- **種類**: 台帳 `kind` = `occupation`（職業）420 / `minor_improvement`（小進歩）416 / `multi_type`（複合）4。
  独立した「大進歩」種別は台帳に存在しない（第1章で詳述）。
- **段階**: #377 §0.3 の定義を継承する。段階1=OR費用（支払い候補の選択）／段階2=他人の手番で発動・
  カードが全員用スペース・カードが畑になる／段階3=帰宅フェイズまたは部屋・住居スロットが条件・対象・発生源／
  段階4=異なる発動サイト2つ以上、または1サイトで3操作系以上／段階外=単一サイト・単一操作で4段階の基盤に依存しない。
  判定は 1→2→3→4→段階外 の順で最初に該当した1つにのみ割り当て、二重計上しない。
  **実装済は段階とは別軸**（#377 §0.3）。段階外は「実装しない」を意味しない。
- **効果**: 仕様JSON `effects[]`。`null`=未調査、`[]`=効果なし確認済み。サイト= `effects[].trigger` のイベント種別（#377 §0.3）。

### 0.4 方法と検算

- Python標準ライブラリ（json / csv / re / collections）による読み取り専用集計。リポジトリのデータ・コードへの書き込みは無い。
- 検算（すべて一致を確認）:
  - 分類表は一意840行・各デッキ168枚。カード名は台帳 `name_ja` と一致（不一致0）。
  - 段階合計は #377 §5.1 と一致: 段階1=16 / 段階2=61 / 段階2関連=4 / 段階3=99 / 段階4=143 / 段階外=452 / 実装済=65。
  - 帯内636＋帯外204=840（完全分割）。
- トリガー生語彙90種を12_family_にグルーピングした（対応表は付録A）。**この家族分けは本文書の分析用グループであり、
  スキーマの公式enumではない**。生語彙のカウントも付録Aに残す。
- 他プレイヤー関与は構造化シグナルの和集合で判定する（定義は第4章）。旧カタログの予備タグは補助信号として併記する。

### 0.5 注意点（データの限界）

1. **#377 は未マージ**であり、5枚（A071/A092/A103/D082/E075）は暫定分類。本文書の段階数値はこの確定版（暫定5枚を含む）を継承する。
2. **仕様JSONは 696/840 の被覆**。帯内636枚は全カバー、帯外は 60/204（29.4%）のみ。仕様無し144枚の内訳は C47 / D46 / E51
   （A119 は PR #397 で仕様追加済み）。効果の型・他プレイヤー関与の構造集計は696枚が母集団であり、840枚への外挿はしない。
3. **実装状態は3つのソースが不一致**（分類65 / 仕様39 / 台帳34）。本文書は分類の65枚を主軸とし、差は第3章で報告する。
4. **トリガー・頻度語彙は未正規化**（trigger 90種 / frequency 30種）。同義語（`any_time`/`anytime`、
   `end_scoring`/`scoring`/`end_game_scoring` 等）が混在する。家族集計は同義語を吸収するが、生カウントは語彙の粗さをそのまま反映する。
5. 公式照合（`verified`）とBGA wiki照合（`bga_checked`）は別軸である（`docs/bga-card-specification.md`）。
   本文書の「実装済」「bga_checked」は公式ルールの正しさを認定しない。

### 1.2 効果の型（トリガー）分布 — 仕様JSON基準（696枚）

被覆: 696枚中 `effects=null`（未調査）72枚、`[]`（効果なし確認済み）17枚、効果あり **607枚**。
効果総数 **780**、原子ステップ総数 918。1枚あたりの効果数: 1個=467 / 2個=121 / 3個以上=19。

トリガー生語彙90種を12家族にグルーピングした集計（家族の定義・対応表は付録A）:

| トリガー家族 | 効果数 | 該当カード数（重複あり） |
|---|---:|---:|
| 出したとき | 210 | 200 |
| アクションスペース使用 | 168 | 152 |
| 常時・いつでも | 106 | 90 |
| 特定行動・建設の後 | 85 | 78 |
| ラウンド開始・終了／労働フェイズ | 75 | 68 |
| 終了時得点 | 59 | 59 |
| 収穫フェイズ | 52 | 49 |
| ゲーム開始・セットアップ | 9 | 3 |
| 他プレイヤーの行動 | 5 | 4 |
| 購入・費用支払い | 5 | 5 |
| 帰宅フェイズ | 4 | 3 |
| その他（単発） | 2 | 2 |
| **合計** | **780** | — |

- 生語彙の上位: `on_play` 204 / `after_worker_space` 123 / `passive` 81 / `end_scoring` 46 / `round_start` 39 /
  `harvest_field_phase` 16 / `ongoing` 16 / `round_end` 15 / `after_renovation` 13 / `harvest_feeding` 13。
- **事実**: 「出したとき」「スペース使用」「常時・いつでも」の3家族で 484/780効果（62.1%）を占める。
  フェイズ連動型（収穫・帰宅・ラウンド境界）は少数派。
- **事実**: 帰宅フェイズのトリガーは仕様上 4効果/3カードのみ。一方、分類表の段階3（帰宅）は22枚（第3章）。
  帰宅効果の多くは仕様JSONで未構造化（`effects=null` 等）か、他トリガー＋条件で表現されているとみられ、
  仕様側の帰宅カバレッジは薄い。
