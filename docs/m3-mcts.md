# M3: 観測からのMCTS（実験版）

- 実行: `cargo run --release --locked -- --mcts --seed 42`
- 探索回数: `--mcts-simulations 48`（探索1手あたり48プレイアウト）。既存`--eval`と排他。
- 木探索はUCT。各手番の探索者はその手番プレイヤー自身の首位獲得確率を最大化する。手の最終選択は勝率を優先し、標本勝率が2.5ポイント以内なら平均得点差で選ぶ。
- 公開済みラウンドカードから各ステージの未公開カードを求め、プレイアウトごとにシャッフルする。ゲームの内部山札・隠しRNGはAIへ渡さない。
- シミュレーション中の合法性は実際のGameエンジンで検証。細部決定はSimpleDetails、プレイアウトは主にM2 EvaluationPolicyを利用。
- 注意：公開Observationには過去の井戸建設ラウンドがないため、将来配給の既存予約を厳密復元できない（探索内は近似）。未公開カードへの情報漏えいではないが評価バイアスになる。
- 本機能の追加は強さの証明ではない。異なる固定シード・先後を交換したベンチマークでM2との差を測定すること。
